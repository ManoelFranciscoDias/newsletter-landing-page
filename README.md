# Newsletter Landing Page

Landing page simples para uma newsletter, feita com HTML e CSS.

## Sobre este repositório

O foco deste repositório é **praticar e testar o uso de Git, GitHub e GitHub Pages**, conforme aprendido no curso "Git e GitHub do básico ao avançado (c/ gist e GitHub Pages)", do instrutor Matheus Battisti (Hora de Codar).

O projeto em si é secundário: o objetivo principal é treinar esse fluxo de trabalho.
